# ☕ Coffee Sales Dashboard – Excel

## 📊 Project Overview

This project is an interactive **Coffee Sales Dashboard** built using Microsoft Excel.

The dashboard analyzes coffee sales data from orders, customers, and products to provide insights into sales performance, customer behavior, product categories, and geographic performance.

The project demonstrates practical **data cleaning, data transformation, analysis, and visualization** using Excel.

## 🎯 Project Objectives

- Analyze overall coffee sales performance
- Identify top-performing customers
- Compare sales across different countries
- Analyze coffee types and roast types
- Explore sales trends over time
- Build an interactive dashboard for business insights

## 🛠️ Tools & Techniques

- **Microsoft Excel**
- Excel Tables
- **XLOOKUP**
- **INDEX & MATCH**
- **SUMIFS**
- IF functions
- PivotTables
- PivotCharts
- Data transformation
- Data visualization
- Dashboard design

## 📁 Dataset

The workbook contains three main data tables:

### Orders
Contains information about individual coffee orders, including:
- Order ID
- Order Date
- Customer ID
- Product ID
- Quantity
- Coffee Type
- Roast Type
- Size
- Unit Price
- Sales
- Loyalty Card status

### Customers
Contains customer information such as:
- Customer ID
- Customer Name
- Email
- Country
- City
- Loyalty Card

### Products
Contains product information including:
- Product ID
- Coffee Type
- Roast Type
- Size
- Unit Price
- Price per 100g
- Profit

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- ☕ Coffee sales by type
- 🔥 Sales by roast type
- 🌍 Sales by country
- 👥 Top 5 customers
- 📅 Sales trends over time
- 💰 Overall sales performance

## 🔍 Key Excel Skills Demonstrated

This project focuses on using Excel to transform raw business data into meaningful insights.

Examples include:

- Using **XLOOKUP** to retrieve customer and product information
- Using **INDEX & MATCH** for data lookup and transformation
- Calculating sales from quantity and unit price
- Creating calculated fields
- Grouping dates by year, quarter, and month
- Building PivotTables for analysis
- Creating charts from summarized data
- Designing an interactive dashboard
